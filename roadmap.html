Forty-five reference pages, five translations, and a set of reader tools built up over the site’s first year. The inventory below is grouped by where a feature lives; the last section lists what is worth adding, with a rough size for each.

Site-Wide Chrome

Present on every page. Built once in tokens.js and tokens.css and shared by all 51 pages.

  • Top navigation

    Sticky bar with the hamburger, wordmark, centered search field, and the bookmark and settings buttons. Scrolling happens in a container beneath it so the scrollbar never runs under the bar.

    All pages

  • Navigation panel

    Full-width panel that drops from the top nav. Two views, Page Type and Task Type, in six columns on desktop (four, three, two, then one as the screen narrows), plus a Site group. The chosen view is shared with the home page.

    Hamburger menu

  • Search

    Live results from a 706-entry index of pages, cards, people, and glossary terms. Recent searches, arrow-key navigation, combobox semantics, and a deep link (?q=) that opens with a query pre-filled.

    Top navigationsearch-index.json

  • Settings panel

    Theme (Light, Dark, Beige, Blue), language (six), and font size (85 to 130 percent), staged until Save. Same layout and styling as the navigation panel; a language change navigates to the matching language URL.

    Settings gear

  • Bookmarks

    A bookmark icon beside every page title saves the page locally; the top-nav bookmark button opens the saved list with remove controls. Stored in the browser, no account.

    Page titlesTop navigation

  • Share

    A share icon beside every title opens a menu for X, LinkedIn, Facebook, Bluesky, and email, plus copy link. Each network gets a summary written to its length limit, with the URL on its own line.

    Page titles

  • Back to top

    Dark round button in the bottom-right corner, colored to the active theme, that appears after 400px of scrolling and returns focus to the top of the page.

    All pages

  • Keyboard navigation

    Left and right arrow keys move to the previous and next page in menu order. Escape closes any open panel. A skip link jumps past the chrome to the main content.

    All pages

  • Themes

    Four palettes driven by design tokens. Blue is the UX Components navy. Illustrations, screens, scrollbars, and focus rings all follow the theme.

    Home heroSettings

  • Footer

    Site links (About, Glossary, People, By Year, Site Map), alphabetized sister sites, and social links. Generated by script so it stays identical everywhere.

    All pages

Home Page

A directory of all 53 references, browsable two ways.

  • Hero

    Logo and title with a Beta pill, one-line subtitle with the live page count, language tabs, and theme tabs. Both tab groups have an animated sliding selection.

    Home

  • Page Type view

    Nine sections, Every Page first then alphabetical, each in a card with an abstract browser-chrome screen of that page type beside the heading and description, and the guidelines three across on a 12-column grid.

    Home

  • Task Type view

    Seven task-based sections in cards, alphabetical, each with a one-line description. The same links, organized by what the designer is trying to do.

    Home

  • Sticky tabs and pills

    Page Type and Task Type tabs with a section pill for every group, pinned beneath the top nav while scrolling. On tablet and phone the pills become a single scrolling rail.

    Home

  • Card descriptions

    Every link carries a seven-word-or-fewer summary, translated into all five languages.

    Home

Reference Pages

The 53 law, effect, principle, and guide pages share one template.

  • Header

    Title with bookmark and share actions, a tagline, and a subtitle.

    All 53 references

  • Feature block

    Formula or quotation, an Origin narrative with linked researchers, the law stated plainly, and a meta row: Coined by, Source, In practice.

    Fitts’s Lawand 44 others

  • When and how to use

    Two columns of bullets under the feature block, written for product managers and designers: the situations where the idea applies, and the moves to make once it does.

    All 53 references

  • Cards

    Eight or more applications per page, each with a themed illustration in browser chrome, a tag, title, description, and meta rows. Illustrations are drawn with shared primitives and a single accent token.

    All 53 references

  • Related chips

    Cards link to the most relevant neighboring page. Every link is mutual, checked at deploy time, and rewired in September for topical accuracy.

    Card meta rows

  • Copy as SVG

    Hovering any illustration reveals a copy button that converts it to a standalone, semantically named SVG on the clipboard, ready for Figma or a document.

    Card illustrations

  • AI section

    A divider and a set of cards on how each law applies to AI-driven interfaces.

    All 53 references

  • Further reading

    Grouped external references in three columns with outbound-link icons.

    All 53 references

  • Structured data

    TechArticle and BreadcrumbList JSON-LD, canonical and hreflang links, and a social image per page per language.

    Page head

Localization and Sharing

  • Five translations

    French, German, Spanish, Japanese, and Chinese, applied as overlays keyed to each page’s structure, plus dictionaries for chrome strings and page titles. Every card, meta row, description, and label is translated.

    i18n.jsi18n/*/*.json

  • Language URLs

    French, German, and Spanish pages live at translated addresses (/fr/loi-de-fitts.html); Japanese and Chinese keep the English slug under their prefix. Server rewrites map every address to the shared page shell, old prefixed addresses redirect, every internal link keeps the language, and a stored language preference redirects plain URLs. Hreflang, canonical, social tags, and the sitemap all use the localized addresses.

    .htaccesspy/gen_slugs.pyPage head

  • Social images

    306 generated preview images, one per page per language, and head-only stubs served to social scrapers so a shared /fr/ link previews in French.

    og/share/

Under the Hood

  • Preflight validator

    Runs before every deploy: balanced markup, translation counts aligned to the page, related chips mutual, People anchors resolving, home count matching the card count, and an identical menu on every page. A failure aborts the upload.

    py/check.py

  • Generators

    Scripts rebuild the search index, sitemap (306 URLs with hreflang and a stylesheet), llms.txt, social images, and scraper stubs from the pages themselves.

    py/gen_*.py

  • Deploy pipeline

    Preflight, a staging copy with comment-stripped assets, then an FTP mirror. Credentials live outside the repository.

    py/ftp_upload.py

  • Server rules

    HTTPS enforcement, language rewrites, scraper routing, and 42 legacy redirects.

    .htaccess

  • Accessibility

    Audited and fixed: skip link, visible focus in every theme, dialog and combobox semantics, forced-colors support, reduced-motion and print styles, 46px close targets.

    tokens.csstokens.js

  • Performance and measurement

    Cache-busted assets, content-visibility on long sections, minified shared files, and Google Analytics.

    All pages

Suggested Additions

Grouped by the kind of value they add. Sizes are rough: Small is an afternoon, Medium a few days, Large a project.

Small afternoonMedium a few daysLarge a project

For Readers

  • Cite this page

    APA, MLA, and BibTeX for every reference, with the original paper’s citation alongside. The Source field already holds most of the data.

    Small

  • Copy as Markdown

    A sibling to Copy as SVG: copy a card, or a whole page, as clean Markdown for docs and design reviews.

    Small

  • Reading time and progress

    Estimated minutes in the header and a thin progress bar under the top nav on reference pages.

    Small

  • Keyboard shortcut sheet

    Pressing ? opens a card listing the arrow keys, search focus, and panel shortcuts. Makes the hidden navigation discoverable.

    Small

  • Shareable bookmark sets

    Encode a bookmark list in a URL so a lead can hand a team the five laws for a project. Bookmarks are local today.

    Medium

  • Flashcard mode

    A study view that shows a law’s name and asks for the one-line statement, drawing on the card descriptions and the serial-position and spacing research the site already teaches.

    Medium

  • Offline support

    A service worker so the site installs and reads offline; the content is static and already cache-busted.

    Medium

For Discovery

  • What’s new

    A public changelog page and an RSS feed. The site changes weekly and nothing announces it; the feed was deferred from the SEO work.

    Small

  • Law of the day

    A rotating pick on the home hero, deterministic by date so everyone sees the same one.

    Small

  • Search filters and fuzziness

    Filter results by page type or task, tolerate typos, and surface people and glossary terms in their own groups.

    Medium

  • Comparisons

    Short pages pairing laws that are often confused: Hick’s and the Paradox of Choice, Miller’s and Cognitive Load, Fitts’s and Steering.

    Medium

  • People network

    A graph of who worked with whom and which laws share researchers, built from the People data.

    Large

For Builders

  • Suggest a correction

    A link on every reference page that opens a pre-filled email or issue with the page and card named. The September accuracy audit found things a reader would have caught sooner.

    Small

  • Embeddable cards

    An embed snippet that renders one law card, with its illustration, on another site, the way a tweet embeds.

    Medium

  • Laws as data

    A laws.json alongside llms.txt: title, statement, coined by, year, tags, related. Feeds the Figma plugin below, the search index, and anyone building on the content.

    Medium

  • Figma plugin

    Browse laws and drop an illustration or a citation card into a file, like the UX Components plugin.

    Large

For Maintainers

  • Add-a-law scaffold

    One script that creates a page from the template, registers it in the menus, home, sitemap, People, and timeline, and stubs the five overlays. Adding Automation Bias took a dozen manual steps.

    Medium

  • Translation integrity tests

    Checks that every chrome key exists once per language and that no overlay entry is still English. The duplicate-key bug that showed Chinese labels on French pages would have been caught.

    Small

  • Link checker

    Re-validate every Further Reading and People URL on a schedule and report dead ones, as the UX Components audit does.

    Small

  • Visual regression

    Screenshot the home page and one reference page in four themes and five languages at three widths on each deploy, and diff them.

    Medium

  • Overlays keyed by ID

    Move translations from selector-plus-index to explicit data-i18n keys, so reordering cards can never silently misalign a language.

    Large
